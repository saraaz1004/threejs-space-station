# Three.js Space Station

Interactive 3D space station built with Three.js and real-time rendering techniques.

This project focuses on immersive 3D visualization, scene management, animations, lighting systems, and interactive camera controls inspired by modern game-engine workflows.

## Features
- Real-time 3D rendering
- Interactive camera movement
- Space station scene system
- Dynamic lighting and shadows
- Skybox and environmental effects
- Animated objects and modules
- Modular scene architecture
- Responsive rendering

## Technologies
- Three.js
- JavaScript
- WebGL
- Vite
- GLSL concepts
- HTML/CSS

## What I Learned
- Real-time rendering principles
- 3D scene organization and optimization
- Camera systems and object transformations
- Lighting, shadows, and material configuration
- Asset loading with GLTFLoader
- Performance optimization in WebGL applications
- Interactive graphics programming

## Project Structure
- `models/` → 3D assets and GLTF models
- `textures/` → texture maps and materials
- `assets/` → additional resources
- `index.html` → application entry point

## Purpose
This project was created to explore computer graphics, interactive systems, and game-development-style rendering pipelines using Three.js.

It reflects my interest in graphics engineering, real-time systems, and immersive applications.
